# ✋ AeroNav --- Touchless Hand Gesture Control for Android

Control any Android app with hand gestures --- no touch required.

## 📱 What is AeroNav?

AeroNav is a native Android app that uses your phone's front camera
and MediaPipe Hand Landmarker to detect hand gestures in real time.

You can: - Move pointer with hand - Pinch to tap - Flick to scroll

Works system-wide and fully offline.

## ✨ Features

-   Real-time hand detection
-   Floating pointer
-   Tap & scroll gestures
-   Background service
-   No internet required

## 🛠️ Tech Stack

-   Kotlin
-   Android SDK
-   MediaPipe
-   CameraX

## 🚀 Setup

1.  Clone repo
2.  Add MediaPipe model
3.  Run app
