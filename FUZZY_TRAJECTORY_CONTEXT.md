# Yvora 2.0-dev
Custom Trajectories mode disables ordinary hand taps/drag/swipe and transform modes. Select one runtime hand and train a distinct path for each of four allowlisted swipes. Open palm twice, pinch as clutch, draw, release. Each path needs at least 5 fresh samples, 400–2500ms duration and sufficient travel. Training requires 3 consistent examples; stores averaged translation/scale-normalized 16-point temporal path and duration locally per hand/command; rejects similar competing templates. Fuzzy matching combines mean/worst spatial error and duration ratio; min aggregation, alpha .80, .15 winner margin. No action on loss/ambiguity, rearm with open palm. Restart engine after edits. Discrete standard Android swipes, not arbitrary path injection. No raw images or network transfer.
Optional Inspect screen locally button in approved navigation overlay: bounded accessibility tree traversal (120 nodes, depth 12) counts visible nodes, enabled noneditable clickable and scrollable nodes and directional actions. Does not access text, descriptions, IDs, screenshots or input values; rejects password nodes encountered, restricted package, lock or unavailable root; excludes editable subtrees. Results advisory only; no clicks or typing, no cloud context, no persistence. Existing review/Run here gate retained. Device testing necessary. Initial structural understanding, not visual understanding or a general screen agent.
