2.0.5-dev: display-only time-based cursor interpolation between observed filtered targets. Normal open-palm cursor updates using Choreographer, nominal maximum ~60 Hz cool and ~30 Hz warm/low-RAM, only while moving. Linear interpolation duration 32–95 ms, restarts from actually rendered integer pixel location, no extrapolation from interpolator, no queued animations, direct snap on rearm or long gaps. Freeze animation before pinch/swipe/drag, loss, mode change, hiding or service teardown. Active drag remains immediate. Existing MediaPipe inference pacing and thermal limits unchanged. Replaces 3px deadband with pixel-level position updates. Does not guarantee device frame rate or eliminate camera/OS delays. Tests cover interpolation, reversal, bounds and cancellation. Includes previous swipe repair PR #19. Phone testing needed.
