# Gesture Studio 2.1 — first stage
Central local registry of 10 discrete commands (four swipes, back, home, zoom in/out, rotate both ways). Separate from cloud AI allowlist. Custom mode exclusively recognizes trained single-hand pinch-clutched moving trajectories. Normal gestures, ordinary tap and continuous drag and two-hand recognizers are inactive in that mode, so default gestures cannot dispatch in parallel; this is isolation, not full cross-mode comparison. Each selected hand's enabled stored patterns are compared; different hand profiles do not compete because only selected hand executes. Three examples learn a 16-point normalized template; fourth independently tests against all competitors. Reject max similarity >=.65 across template and examples; .40–.65 warning; runtime requires >=.80 and margin >=.15. Recheck before save. Same command may replace its own template; delete conflicting command explicitly and retrain. Legacy swipes migrated on read; deletion tombstone prevents resurrection. No raw frames stored. Existing thermal, identity, lock screen, AI/drag/transform guards remain. Canvas patch included and PR22 CI succeeded. No device test yet. Next: separate static pose feature registry, customizable pointer/tap/continuous drag with ownership and duration conflicts, simultaneous two-hand patterns, combined default/custom conflict model, device benchmark session. This stage does not implement arbitrary un-clutched gestures or simultaneous use with normal mode.
