V2.0.7-dev. Replaces per-cursor WindowManager relayout during animation with one fixed translucent non-touchable hardware-accelerated custom Canvas view. Both cursors retain independent position, colors, ownership and cancellation. Coalesced postInvalidateOnAnimation only on visual change. The shared layer is invisible when neither cursor is shown. Preserves old rendering automatically if attach fails; explicit compatibility switch disables shared layer after restart. One window alpha .50, but apps/system may reject obscured touches; device testing required. Measured moving draw callbacks/sec and tracking results/sec plus frame age in existing diagnostics; draw count is not display refresh rate or proof of physical motion latency. Inference, camera resolution, gesture rules and thermal policy unchanged. Full-screen translucent layer can increase GPU composition cost and may be blocked by sensitive apps; no performance claim without measurements. Gesture Registry customization/conflict redesign not part of this stability patch.
