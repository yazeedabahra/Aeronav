# Gesture reliability 1.2.1

Device report: horizontal swipe and drag did not work reliably in 1.1. Code review found strict camera-relative travel/speed gates, single-frame finger-count reset, and image-relative pinch threshold conflicting with three-finger poses. Changes: aspect-corrected joint geometry and palm-relative pinch/travel, one-count-drop tolerance, longer swipe window, real initial Android long press as one stroke before continuation, green indicator only when Android initial stroke completes, live finger mask, pinch ratio and dispatch request/rejection status. Three-finger poses still take priority before pinch ownership; relax other fingers to start a pinch (the middle/ring/pinky pose with tips touching is intrinsically ambiguous). Pinch holds own input until release. Legacy vertical classifier preserved. Tests include synthetic ten combinations, not live camera recognition. Dispatch accepted is not proof an app moved an item. Physical-device test required. Thermal limits unchanged.
