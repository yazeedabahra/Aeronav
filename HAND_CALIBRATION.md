# Independent hand calibration — 1.6-dev
Existing shared camera region migrates to both slots by default; independent profiles and shared profile are stored separately. Link copies selected effective range to shared, unlink restores separate profiles. Each cursor maps its own region to the full screen, X/Y spans 10–100%, independent centers. Changes live; actual touch injection remains disabled while Safe calibration is enabled. Editing sliders activates safe calibration; turn it off after adjusting. Auto calibration samples selected labelled open palm only, 2–15 sec, at least 10 valid samples and movement >=8% on both axes; trims outer 5%, previews measured range before approval. No raw camera frame or coordinates stored/transmitted. Cancels on pause, thermal stop, expired/stale data, AI ownership, selection change. Edge compensation uses a 2.5% inner margin; existing speed-adaptive pointer filter is retained independently. The 10% range can amplify jitter; start with 40–60%. No real-device validation yet.
