# Tutorial 2.0.2-dev
Nine bilingual steps: welcome, permissions, camera/calibration, ordinary gestures, optional live practice, transform modes, personal/custom training and fuzzy lab, local/cloud AI, start/stop and troubleshooting. First launch opens the guide before permission prompts; Finish/Skip persists locally, and the main screen button reopens it. Language can be changed inside the guide. Permission requests are explicit; no automatic activation of Accessibility. Practice uses existing camera engine in safe calibration, reads fresh timestamped tracking samples, locks to one hand, requires two distinct open-palm frames, movement, pinch and release; no Accessibility injection. It stops a service started for practice when leaving or completing; preexisting engine remains in safe calibration (user must explicitly disable it afterward). No completion gate on permission or practice. Tests exercise sequencing, stale frames and hand loss. No real-device verification yet; practice only confirms detected movement, not actual Android gesture success.
