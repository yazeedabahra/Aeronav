# Pinch drag and drop

Short pinch: tap on release at the original pointer location. Hold for 350 ms: request a continuous touch on Android API 26+, holding at the origin for the OS long-press timeout plus 80 ms before moving. While held, calibrated pointer displacement moves the target. Open fingers to release. Three detected extended fingers have priority before a pinch is acquired; an acquired pinch owns input until release. Pinch hysteresis reduces accidental release. Loss of tracking, stale results, calibration, engine shutdown or gesture cancellation stop the active touch; a 650 ms sample watchdog ends the continued stroke. Other accessibility commands are rejected while the drag dispatcher is busy. Android 7 retains tap on release without continuous drag. Pointer overlay center is aligned with touch coordinates. Apps decide their own drag/long-press behavior. No new dependencies. Unit tests cover recognition, not system dispatch or physical devices. Validate actual gesture combinations, hold timing, release, and target alignment on device before release.
