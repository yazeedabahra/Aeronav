# Dual independent cursors (1.4-dev)
Two independent recognizers and position filters, using a single MediaPipe instance configured for up to two hands. Cyan left / amber right use existing mirrored display convention; verify physical handedness on target phone. Ambiguous/duplicate labels are suppressed; no hand assignment based on array order. Each hand must present an open palm after loss or contention. One active Android touch stream at a time; both cursors move independently, either can initiate a pinch/tap/drag or existing swipe if no competing touch. Multi-touch zoom, simultaneous dragging, free-form AI gesture intent and true device tests are NOT implemented. Optional single-hand mode (restart required) reduces inference load; thermal protections retained. Tests cover routing and touch arbitration, not real-camera accuracy.
